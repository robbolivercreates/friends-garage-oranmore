# Hero Video

Drop the homepage hero video here with this exact name:

```
public/videos/hero.mp4
```

The site detects it automatically — while the file exists, the homepage hero
plays the video (muted, looping, inline on mobile). If the file is removed,
the hero falls back to the still image (`/images/garage/hero.jpg`), which is
also used as the video poster/first frame.

## Recommended specs

- **Format:** MP4 (H.264), 1920×1080 landscape
- **Length:** 5–15 seconds, seamless loop if possible
- **Size:** under ~8 MB (compress with HandBrake if needed)
- **Look:** dark, moody workshop footage works best with the site's design —
  the text sits on the left, so keep the subject on the right side of frame
- **No audio needed** (the video always plays muted)

Tip: generate it from a real photo of the garage with an image-to-video
tool (Sora, Runway, Kling, Luma) using a slow, subtle camera move.
